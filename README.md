# dmainplus

赞助域名发布与管理界面。

## 功能
- 前台需要输入访问密码后才能查看专享域名列表
- 域名列表支持一键延迟测试
- 后台管理员登录后可修改前台密码、管理域名、发布公告
- 所有密码均使用 Bcrypt 哈希存储，接口加固并启用安全响应头

## 快速开始
1. 安装依赖
   ```bash
   npm install
   ```
2. 启动服务
   ```bash
   npm start
   ```
3. 在浏览器访问：
   - 前台页面：`http://localhost:3000/`
   - 后台页面：`http://localhost:3000/admin.html`

## 默认凭据
- 前台访问密码：`user123456`
- 后台管理员密码：`admin123456`

请尽快在后台更新为自己的强密码，并在生产环境设置环境变量 `APP_SECRET` 为足够复杂的随机字符串。
